# Zotero 库导出指南

## 导出步骤

1. 打开 Zotero 桌面应用
2. 选中"我的文库"或要导出的集合
3. 文件 → 导出条目
4. 格式选择: CSV
5. 保存到: `config/zotero_library.csv`
6. 建议每次文献监控前更新一次导出

## 需要的列

- `title` (标题)
- `doi` (DOI)
- 其他列可选保留

## 注意

- 如果库中没有某篇论文的 DOI，去重时会依赖标题匹配（准确度略低）
- 导出的 CSV 编码应为 UTF-8，避免中文乱码
- 每次在 Zotero 中新增或删除文献后，请重新导出 CSV 以保持同步
